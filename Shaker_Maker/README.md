# 記憶萬花筒 · Nostalgic Shaker Maker

以原生 HTML、CSS、JavaScript 製作的小物收藏互動頁面。選擇容器、放入記憶裡的小物、搖動構圖，再將當下畫面下載為 PNG。無執行期套件依賴，不需要建置。

本文件整合最終操作、設計、程式架構、素材維護與驗收說明；舊階段紀錄及規格另行備份，不隨專案上傳。

## 開啟專案

可直接開啟 `index.html`，也可使用本機 HTTP 伺服器：

```sh
cd Shaker_Maker
python3 -m http.server 8000 --bind 0.0.0.0
```

電腦瀏覽 `http://localhost:8000`。終端機保持開啟，完成後按 `Control + C` 停止。

### 手機測試

1. 手機與電腦連接同一個 Wi-Fi。
2. 在 Mac「系統設定 → Wi-Fi → 目前網路詳細資訊 → TCP/IP」查看 Mac IP。
3. 手機瀏覽 `http://<Mac IP>:8000`，例如 `http://192.168.1.25:8000`。
4. 手機橫向使用；直向會顯示旋轉提示。若 Mac 防火牆詢問連線，允許測試伺服器連入。

指令中的 `0.0.0.0` 不需替換；只有手機網址需要填入 Mac IP。

## 製作與收藏

1. 選擇背景與容器：紙箱、綠油精、塑膠袋。
2. 從素材收藏庫加入小物。同一素材可加入多件；數量徽章顯示目前使用數量。
3. 選取並拖曳小物，在右側調整大小、旋轉、前後層級與動態。
4. 可變色 SVG 可調整顏色；懸掛物件可選細線或六種懸吊素材並獨立選色。
5. 按「完成製作」進入搖動模式。拖曳搖動區、按「搖一搖」，或使用方向鍵及空白鍵。
6. 按「收藏現在的樣子」下載 1600 × 1600 PNG，完成後仍留在搖動模式。
7. 「回到原本排列」重建原構圖的模擬；「返回編輯」回到進入搖動前的構圖。「重置」清空本次製作。

小物大小範圍 40%～180%，旋轉範圍 −180°～180°。若大小或角度無法放入容器，保留先前設定；切換容器時會將小物移至安全位置，無法容納時拒絕切換並提示縮小。

### PNG 收藏

收藏截取 `machine` 當下的正方形範圍，包含範圍內背景、容器、懸吊線、裝飾物、框線及玻璃圖層，不含控制台、按鈕或選取框。下載期間暫停模擬並阻止搖動輸入，完成後恢復原模式。

作品與自訂圖片只存在本次頁面，重新整理會清除。專案不提供 JSON 匯入／匯出、localStorage 儲存或自動載入；收藏成果為 PNG。

### 自訂圖片

支援 PNG／WebP，每張最多 5MB、1600 萬像素。保留原色與長寬比例，透明留白不作為放置範圍。損壞、非支援格式及全透明圖片會被拒絕，不影響已加入的小物。

圖片留在裝置上，不上傳伺服器。可重複加入同一自訂素材；移除最後一件或重置時，會釋放暫時圖片 URL 並移除素材庫項目。建議使用靜態 WebP，動畫圖片的輪廓不保證涵蓋每一影格。

## 版面與互動設計

- 繁體中文介面與 `zh-Hant` 語言標記，英文保留作視覺副標。系統字型以 Noto Sans TC、PingFang TC、Microsoft JhengHei 為優先。
- 頁面固定於視窗，整頁 `overflow: hidden`；素材庫與控制面板可內部捲動。
- 頂列與左右面板採霧面玻璃、柔和反光與陰影；選項選取色為 `#3c2c53`。
- 選項按鈕使用 200ms ease-out 位移動畫；快速切換延續目前位置，背景載入使用快取與版本檢查避免舊選項覆蓋新選項。
- 製作圖層維持正方形；搖動操作區置中，寬度為高度的兩倍。水平移動最多容器寬度的 ±50%，垂直維持 ±6%。
- 按鈕支援焦點、停用狀態及原生鍵盤操作；裝飾性圖層不參與輔助技術閱讀。`prefers-reduced-motion` 停止持續動態，明確操作時播放短暫搖動。

## 放置輪廓與物理

容器邊界為使用者確認的固定多邊形，存於 `main.js` 的 `defaultMachinePolygons`，以 0～1 正規化座標與 Back／Frame／Front 共用正方形座標。頂點資料凍結，使用者不能編輯放置範圍。

放置區域不包含瓶蓋、袋子提把；紙箱側面可放置。拖曳、選取線框、縮放旋轉與動態碰撞共用素材可見輪廓，依旋轉縮放後的輪廓與 0.004 邊距求允許的物件中心範圍，超出時修正至最近邊界。

目前 `deco_3.png` 為原 `deco_4.png`，目前 `deco_4.png` 為原 `deco_5.png`。兩張輪廓已依現有圖片重新偵測，使用 256px、alpha ≥ 16 的保守凸輪廓；`deco_1`、`deco_2` 保留原 alpha ≥ 128 取樣。輪廓以素材 ID 查找，不依賴顯示名稱。

自訂圖片與可變色 SVG 在載入時取樣一次；拖曳與物理更新不讀取透明像素。輪廓是凸多邊形近似，包含凹口與內部空洞，不是逐像素碰撞。

動態包括落下、漂浮與懸掛，時間以秒計算並使用有限子步。懸掛每次進入或還原時重建錨點，碰到容器邊界時可能縮短線長；裝飾之間可重疊，沒有物件間碰撞。

Safari 懸吊定位由外層 `<g>` 控制位移與旋轉，內層 SVG 僅處理比例與裁切，避免巢狀 SVG 的 transform 相容性問題。

## 素材與顏色

`assets/` 保存原始圖片；`assets/background-preview/` 是按比例縮小的背景顯示圖，原始背景保留。

- `assets/deco/`：四張原色 PNG，使用目前編號。
- `assets/colorchange_deco/`：七張可變色 SVG。1、2、4、5、6、7 各一個色彩通道；3 提供中心、背景、角落三個通道，白色分隔線保持原樣。
- `assets/hang/`：六張懸吊 SVG，加上原生細線選項。維持原圖比例，放大兩倍後裁切中央線段，顏色依透明度獨立套用。
- `assets/machine-back/`、`machine-frame/`、`machine-front-glass/`：三種容器的分層圖。

SVG 選色依實例獨立保存，可恢復原色；原圖不被覆寫。原色 PNG 與自訂 PNG／WebP 不提供選色。

## 程式架構

| 檔案                              | 職責                                            |
| --------------------------------- | ----------------------------------------------- |
| `index.html`、`style.css`         | 介面結構、繁體中文文字、版面及視覺效果          |
| `main.js`                         | 素材目錄、固定輪廓、狀態、製作操作與介面更新    |
| `physics.js`                      | 落下、漂浮、懸掛及容器邊界修正                  |
| `shake.js`                        | 搖動模式、輸入、動畫迴圈與懸吊線定位            |
| `uploads.js`                      | 本機 PNG／WebP 驗證、透明輪廓與暫時資源生命週期 |
| `recolor-assets.js`、`recolor.js` | SVG 原始來源快照、獨立選色、預覽與快取          |
| `buttons.js`                      | 選項按鈕動畫、尺寸快取與減少動態處理            |
| `collection-export.js`            | 當下容器畫面合成與 PNG 下載                     |
| `collection-export-assets.js`     | 本機 HTML 收藏用的自動產生圖片資料              |
| `scripts/`、`tests/`              | 語法／引用檢查、素材生成與回歸測試              |
| `.github/workflows/check.yml`     | GitHub push／pull request 自動執行測試          |

Machine 的顯示順序為 Back → Rope → Items → Frame → Front → Selection。搖動模式隱藏選取框與製作面板，模擬與原構圖分開管理，返回編輯不覆寫原構圖。

## 開發與素材維護

需要 Node.js 22 或更新版本；不需 `npm install`。

```sh
npm test
npm run generate:assets
```

`npm test` 執行語法、HTML 引用、物理、透明輪廓、SVG 選色、懸吊定位及生成素材一致性檢查。

更換或重新命名素材時：

1. 更新目錄中的 ID、路徑與顯示名稱。
2. 若裝飾圖形改變，更新 `decoFootprints` 或重新偵測輪廓；若容器圖改變，重新確認固定放置多邊形。
3. 若可變色 SVG 原圖改變，同步更新 `recolor-assets.js` 的原始 SVG 快照與色彩通道；測試會偵測來源不一致。
4. 執行 `npm run generate:assets`，更新本機 PNG 收藏素材。
5. 執行 `npm test`，並重測製作、搖動、選色與下載。

直接開啟 `file://` HTML 時，收藏才載入 `collection-export-assets.js`，使用內嵌圖片避免 Canvas 來源限制。HTTP 模式直接使用原圖。生成檔需要保留於版本控制；其一致性由測試驗證。

`.prettierrc.json` 定義 2 空格、100 字寬、單引號及尾端逗號。手寫程式維持工程師閱讀排版；內嵌圖片與 SVG 來源檔為生成資料，不做手動排版。

## 小作品儲存庫與 GitHub

本作品獨立存放於 `26frontend-mini-projects/Shaker_Maker/`，由 `26frontend-mini-projects` 根目錄的 Git 儲存庫管理。此儲存庫僅放置小作品，不提供作品集總覽或入口目錄。作品頁面為 `Shaker_Maker/index.html`，可由既有作品集直接連結。

從儲存庫根目錄提交與推送，不需建立獨立儲存庫或另設 origin：

```sh
git add Shaker_Maker .github/workflows/shaker-maker.yml
git commit -m "Add Shaker Maker mini project"
git push origin main
```

GitHub Actions 設於根目錄 `.github/workflows/shaker-maker.yml`，在 `Shaker_Maker` 目錄執行 `npm test`。

若以 GitHub Pages 發布此儲存庫，作品路徑為 `/26frontend-mini-projects/Shaker_Maker/`。所有程式與素材使用相對路徑，無需建置。歷史文件與原獨立 Git 設定另存於專案外備份。
